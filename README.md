# Neural Spaceship Sandbox Demo
Neural Spaceship Sandbox is a hybrid turn-based strategy and voxel sandbox with unlimited possibilities. Build custom spaceships, arm them to the teeth with advanced sci-fi weaponry, pilot them or hand the keys to our advanced AI, and then use them to conquer the galaxy / galaxies!
